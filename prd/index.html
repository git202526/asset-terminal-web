一、产品概述

1.1 背景

个人财务管理分散在多个工具中：工资/社保算不清、多张银行卡余额分散、应收应付靠记忆、保单与债务无台账、年度收支无法自动汇总。本产品将收入、支出、资产、负债、经营、保障聚合到单一终端，用一个账户体系统一管理。

1.2 目标用户

  • 有固定工资收入、需核算五险一金与个税的个人
  • 持有多张银行卡/账户、需要统一管理余额的个人
  • 有房屋租赁等副业经营、需要项目级收支核算的经营者
  • 有应收应付账款、保单、债务需要台账管理的个人

1.3 核心价值

  1. 工资自动化：五险一金自动计算、四标签自动判定、个税累计预扣参考
  2. 资产全景：净资产、资产分布、现金流趋势、财务健康度一屏掌握
  3. 多账本隔离：生活/经营/工资账本流水互不干扰，总览全局聚合
  4. 数据自有：本地IndexedDB全离线 + GitHub云同步，数据不依赖第三方服务
  5. 多端一致：Android壳 + 电脑浏览器访问同一远程网页，数据云同步

三、功能需求详述

3.1 总览 Tab

功能 需求说明
净资产 Hero 总资产 − 总负债，大数字展示（红色系=盈利/上涨方向）
本月收支 本月收入、本月支出两个统计卡
资产分布图 各资产分类占比饼图
账户分布图 各账户余额占比饼图
本月收支构成 收入/支出分类构成图
近6月现金流 收入/支出柱状趋势
净资产趋势 净资产折线变化
账本汇总 各账本收入/支出/结余汇总
到期提醒 还款、应付、保费等到期事项
财务日历 还款/应付/周期记账/工资/保费，支持「待办/金额」双模式切换
四宫格 资产/债务/经营/保障 入口
快捷功能宫格 高频操作入口（报表、健康度、日历等）
财务健康度 多维评分与建议

规则：总览只做数据分析展示，不放置快速记账入口。

3.2 记账 Tab

功能 需求说明
记账表单 支出/收入切换；金额；四级分类联动（一级→二级→三级→四级）；入账账户；备注；标签；凭证图（附件）
本月流水 当前账本当月流水列表（分收入/支出）
流水查询 二级页：按月浏览、按分类/账本/方向筛选、搜索
月预算 总预算 + 分类预算 + 进度条 + 百分比 + 超支提醒
年预算 年度总预算 + 进度条（独立开关）
周期记账 每月自动待记模板（新建/编辑/删除）
记账管理 汉堡菜单：分类管理、账本管理、快捷模板、自定义标签

规则： - 流水记入「当前账本」（账本切换器在记账页顶部） - 预算按账本隔离（月预算+年预算） - 周期模板到期待记，不自动入账（人工确认）

3.3 账户 Tab

功能 需求说明
资金池列表 按账户分类分组展示（现金/储蓄/虚拟/信用/投资/债权/负债）
账户分类管理 分类新建/改名/删除（预设可删，删后账户归入「其他」）；支持「充值」类（会员卡/公交卡/饭卡/押金）
账户 CRUD 新建（含分类、银行、尾号、余额）、编辑、删除
资金转账 池间互转，同时更新两个池余额并记录流水
对账冲正 余额与实际不一致时，生成「对账冲正XX银行 余额调整」流水
最近操作 转账/对账历史

3.4 工资 Tab

功能 需求说明
工资设置 社保基数、公积金比例（默认8%）、基本工资、调薪
月度录入 月份、应发自动折算、实发手动输入、备注扣款、大病保险手动标记
五险一金明细 养老/医疗/失业/工伤/生育/公积金：基数、企业缴纳、个人缴纳、比例；企业综合成本
四标签判定 良好/优秀/高温/大病保险，独立标记、单月可多标签
年度四标签统计 各标签年度计数
工资税务 个税累计预扣参考、年终奖独立计算
年度汇总 全年工资/五险一金/个税汇总
调薪预览 调整基数后模拟各月应发变化
历史记录 按月列表，历史标签不重算

核心算法： - 公积金双边 = 个人(基数×8%四舍五入) + 企业(基数×8%四舍五入) - 应发 = 基本工资按基数比例自动折算 - 企业综合成本 = 应发 + 企业五险 + 企业公积金 - 优秀(+180)/高温(+300)记奖励补贴，不计入应发 - 大病保险不自动判定，用户当月金额异常（如年度一次性扣款）时手动标记

3.5 我的 Tab

功能 需求说明
快捷宫格 新建账户、账户管理、记账管理、工资设置
云同步与账号 GitHub Token配置、立即同步、自动备份开关
数据备份与恢复 全量备份JSON导出/导入、自动备份
报表导出 CSV、Excel(xlsx)、长图
CSV导入记账 按账本导入、模板示例
外观与字号 5套主题（清新绿/晨曦橙/商务蓝/暗夜绿/深邃紫）+ 字号调节
账本管理 账本新建/切换/重命名/删除
到期提醒 还款/应付/保单/周期记账提醒设置
应用锁 进入App密码锁
系统状态 存储模式、账户/流水统计、云存储连接状态

3.6 资产域

功能 需求说明
投资持仓 名称、成本、现值、盈亏、收益率

四、核心业务规则

规则 说明
红涨绿跌 收入/上涨/盈利=红(#e04545)，支出/下跌/负债=绿(#1ba06a)
账本隔离 流水归属当前账本；总览聚合所有账本/账户
多标签 四标签独立标记，单月可多标签，不合并
历史不重算 调薪后修改基准，历史月份标签不变
池间互转 一笔记账同时更新两个池余额
对账冲正 生成「对账冲正+银行+余额调整」类型流水
分类删除 预设分类可删，删除后相关记录归入「其他」
借出款回收 只作资金形态转换，不计收入
导出 导出值 = 当前账本流水（可全量）

六、技术方案

6.1 架构

┌─ 客户端 ─────────────────────────────┐
│ Android壳(Capacitor WebView)          │  ← 打开即加载远程网页
│    ↓ 固定URL                           │
│ GitHub Pages 远程网页                 │
│  ├─ index.html（5Tab+宫格+二级页）     │
│  ├─ app.js（业务逻辑，~4700行）        │
│  ├─ style.css（5套主题+桌面适配）      │
│  ├─ db-offline.js（IndexedDB封装）     │
│  ├─ api-offline.js（离线API层）        │
│  └─ sw.js（Service Worker 网络优先）   │
└──────────────────────────────────────┘
        ↕ GitHub Contents API（云同步）
┌─ 云存储 ──────────────────────────────┐
│ git202526/asset-terminal/data/cloud-sync.json │
└──────────────────────────────────────┘

6.2 关键机制

机制 说明
远程壳 Capacitor壳URL固定（?v=20260922h），永不改；更新只需push网页
缓存策略 Service Worker网络优先，CSS/JS带?v=参数强制更新
版本提示 启动对比 version.txt 与 APP_VERSION，发现新版显示绿色提示条（点击手动刷新，不自动跳转）
云同步 5秒防抖push、启动静默pull合并；登录后显示云存储状态
桌面端 ≥960px：左侧固定导航 + 总览双栏仪表盘 + 各Tab双栏适配
移动端 <960px：底部5Tab + 单栏布局

6.3 技术栈

  • 前端：原生 HTML + CSS + JS（无框架）
  • 图表：ECharts 5.5（本地vendor，不依赖CDN）
  • 壳：Capacitor 6 → Android APK
  • 存储：IndexedDB + localStorage
  • 云同步：GitHub Contents API（REST）
  • 托管：GitHub Pages（git202526/asset-terminal-web 公开仓库）
